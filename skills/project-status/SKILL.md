1. List open issues: number, title, whether a branch or PR exists.
2. List open PRs: linked issue, check status, latest review verdict, unresolved comments.
3. Name issues that wait for an answer from the maintainer.
4. Propose the next issue to work on, with one sentence of reasoning.
